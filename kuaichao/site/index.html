怎麼玩

  1. 點一張點菜單，選你要炒的那道。
  2. 開火、下油，照單下料和調味（紅點＝還缺的）。
  3. 往上滑甩鍋，按住拖曳用鍋鏟翻炒。炒熟、拌勻，大火甩出鍋氣。
  4. 按「出菜」。等太久或太難吃，口碑會掉；三顆心掉光就收攤。
  5. 打烊後賺的錢存進存款，去商店換好鍋、加爐子、升級店面。
  6. 買了炸鍋：放料 → 裹地瓜粉 → 往下滑放籃子 → 炸到金黃 → 往上滑拉起、點一下甩油 → 撒胡椒鹽 → 出菜。
小技巧：熱油再下蒜、薑、辣椒會爆香；鍋子夠熱時下米酒會嗆鍋；不翻不甩，鍋底會焦。
電腦：空白鍵甩鍋（Shift＋空白大力甩）、Enter 出菜、1／2／3 切換爐子和炸鍋。
炸鍋：油溫 165°C 以上才會酥；炸過拉起來，等一下再用 180°C 下鍋就是「複炸」，更酥。
