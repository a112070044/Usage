# 💞 今天去哪玩

把想去的地方一個一個加進來，不知道要去哪的時候按一下，從**還沒去過**的地方隨機抽一個。

## 功能

- ➕ 首頁直接加地點：輸入名稱、點一下分類（想吃的、景點…）就好，地圖連結和備註選填；貼 Google 地圖網址也能自動帶出名稱
- 🎲 從沒去過的地點隨機抽，可以指定清單（例如「想吃的」「景點」），也可以只抽離目前位置幾公里內的
- 🔄 不想去就換一個，最近抽過的會盡量避開
- ✅ 去過了就打勾，之後不會再抽到（可以在清單裡改回來）
- 📥（選用）一次匯入 Google Takeout 的已儲存清單（`.csv`）和加星號地點（`Saved Places.json`），重複匯入不會重複
- 💾 匯出／匯入備份，用來在兩個人的手機之間同步（會合併，不會互相覆蓋）

資料只存在瀏覽器（localStorage）裡，不會上傳到任何地方。

## 兩個版本

| 檔案 | 說明 |
|---|---|
| `index.html` | 單機版：資料存在各自手機，可整批匯入 Google 地圖、只抽附近的、匯出／匯入備份 |
| `shared.html` | 兩人共用版：發佈在 claude.ai 上，兩個人加的地點存在同一份清單、自動同步（線上版：https://claude.ai/artifact/Uvz2zHAgf6TMdL2rjBezZn ，要在 Share 把對方設為 Contributor）。在 claude.ai 以外打開時，資料只存在這台裝置 |

## 使用方式

只有一個檔案 `index.html`，不需要安裝任何東西：

- **直接用**：用瀏覽器打開 `index.html`
- **放上網路（建議，手機才好用）**：在 GitHub repo 的 **Settings → Pages** 選擇這個分支後，網址會是
  `https://<帳號>.github.io/<repo>/date-spots/`。用手機打開後「加入主畫面」，就像一個 App。
  > 「只抽附近的」需要定位，瀏覽器只允許 `https://` 網址使用定位，所以要用這個方式開。

## （選用）從 Google 地圖整批匯入

1. 電腦打開 [Google Takeout](https://takeout.google.com/)，先按「取消全選」
2. 勾選 **已儲存**（Saved）和 **地圖（您的地點）**（Maps (your places)）
3. 建立匯出 → 下載 zip 並解壓縮
4. 到網站的「📥 匯入／備份」，把 `Saved` 資料夾裡的 `.csv` 和 `Saved Places.json` 一起選進來

> 已儲存清單的 CSV 沒有座標，所以「只抽附近的」只對加星號地點（有座標）或網址裡帶座標的地點有效。
